Hot Games Tutorial Hub

Run locally:
1) python3 -m http.server 8000
2) Open http://localhost:8000

What is included:
- Aggregated tutorial cards for hot and upcoming (2026+) games.
- Supports articles, videos, images, and detailed instruction entries.
- Search + filters by keyword, genre, platform, release window, and content type.
- Lightweight CMS panel to create, edit, and delete content (stored in localStorage).
- API integration placeholders for YouTube, Twitch, and Steam in app.js.
- SEO-friendly metadata, responsive mobile-first layout, and Google Analytics gtag placeholder.
